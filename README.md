# Sophrosyne · 临朝

> 个人自用、AI 辅助开发的 Web/PWA 自制力应用（v0.4.0）。

## 依据

把 Yicheng Ren《如何提高自制力》一文的两代自控技术——**CTDP（链式时延协议）** 与
**RSIP（递归稳态迭代协议）**——封装进「古代皇帝临朝治国」题材，以原文理论为底层设计依据。
详见 `sophrosyne-design-v0.3.md`。

## 用途

仅供本人使用：不靠意志力、不靠外部监督，通过「仪式 → 临朝 → 廷议 → 制度沉淀」闭环改善行为，
并用「朝代更替」叙事让失败成为可复盘、可继承的资产。**无胜利条件，只有结算点。**

## 运行

```bash
python -m http.server 8000   # 或 npx --yes http-server -p 8000
```
打开 `http://127.0.0.1:8000/`。PWA 离线仅在 http(s) 下生效。

## 说明

- 纯前端 + `localStorage`（键 `sophrosyne.v6`，自动迁移 v5/v4 旧档），无后端；可选接入 OpenAI 兼容 LLM 做「史官 AI」风味化。
- 目录：`js/`（模型/引擎/UI）、`assets/`（WebP 美术资产）、`tools/`（资产处理脚本）、`test/`（单元/冒烟测试）。
- 版本三要素：应用版本用 SemVer（见 `manifest.json`）；存储键 `sophrosyne.v6` 仅数据结构变化才 bump；`sw.js` 的缓存键仅用于离线刷新。

## 变更记录

- 国力模型（20 存量 + 派生）与 24 个政务/事务场景。
- 勤政链（三三制）+ 廷议（废黜/成例）+ 预约（履约/失信）。
- 典章制度树（固化度 + 升级/强化/复活/迁都）、谥号四维 + 庙号 + 奉先殿实录、子嗣培养继位。
- 政务/事务/预约按发生地点分布到各殿，各殿一级按钮承载动作，顶部可交互状态栏。
- 年龄修复（现实 1 天 = 在位 1 年）、阶段目标多标准（政务总数/国力指标/制度天数）。
- 美术资产 WebP 优化、引入 git 版本控制与 SemVer。
