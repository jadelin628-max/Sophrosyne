# Sophrosyne · 临朝

一款**仅供个人使用**的 Web / PWA 应用，把「如何提高自制力」一文（Yicheng Ren）的两代自控技术
**CTDP（链式时延协议）与 RSIP（递归稳态迭代协议）** 封装进「古代皇帝临朝治国」题材。

> 设计文档：`sophrosyne-design-v0.3.md`。当前为**阶段 A 重构版（v4）**。

## 运行方式

```bash
python -m http.server 8000   # 或 npx --yes http-server -p 8000
```
打开 `http://127.0.0.1:8000/`。PWA 离线仅在 `http(s)` 下生效；`file://` 直接打开也可用（无离线）。

## 数据存储

`localStorage`，键 `sophrosyne.v4`，无后端。页内「⚙ 设置 → 重置/导出/导入」。

## 核心机制

**国力（21 项具体指标）**：人口/岁入/粮储/国库/皇威/疆域/民心/生活水平/耕地/工坊/商户/治安/失业率/文治(秀才·举人·进士)/科技/军队/训练率/装备率/基建/腐败/外交。不同政务/制度影响多项，可增可减；自然增长率小量、政务大量；国库=每年岁入累计。

**政务/事务场景（24 个）**：御门听政、召见大臣、批阅奏折、微服私访、主持科举、编纂典籍、督造工程、筹措军备、经筵讲学、处理刑狱、赈灾济民、出使邻邦 + 12 项内廷修身。每个场景有预约前置；主要/次要政务由用户自选；真实任务由用户输入。

**预约（容朕三思）**：预约前置 → 履约则威望 +1、失信则威望 -1（无守信指数，威望并入个人属性，较大影响国力效率与谥号）。

**岁末结算**：白天记录的真实事务，在「岁末结算」时（无 LLM 按场景默认增减；配 LLM 则由大模型把一日现实任务折算为一年皇帝政务、按月风味化并决定增减）落为起居录。

**典章制度树**：父/子节点 + 自拟分组 + 固化度（坚持天数决定，失守减半、驾崩不归零）。

**谥号/庙号**：按「登基以来各指标增减」结算，载入太庙实录并附依据。

**大模型（史官 AI）**：OpenAI 兼容接口（自填 Base URL/Key/模型），提示词含世界观与历史上下文（本朝起居录 + 前朝实录）。

## 目录

```
index.html / styles.css / manifest.json / sw.js / icon*
js/metrics.js   国力指标模型（存量/派生/自然增长）
js/scenes.js    政务/事务场景模板 + 属性常量
js/store.js     数据层（localStorage）
js/score.js     谥号庙号（增减结算）
js/engine.js    引擎（临朝/岁末结算/威望/制度树/驾崩）
js/llm.js       大模型（一日转一年 + 史官评语）
js/ui.js        渲染与交互
js/app.js       启动入口
test/*.test.js  单元/冒烟测试
```

## 阶段计划

- **阶段 A（已完成）**：国力指标、场景、威望、增减结算、LLM 一日转一年、制度树固化度/分组。
- **阶段 B（已完成）**：谥号双轨(LLM)、国策等级/升级/复活/强化、突发事件状态机、阶段目标、子嗣培养、君主年龄/寿命。
- **阶段 C（已完成）**：紫禁城 2D 俯视皇宫界面（SVG 手绘，点建筑进殿宇）+ 古韵美化。真实图片素材可放入 `assets/` 文件夹后替换 SVG。
